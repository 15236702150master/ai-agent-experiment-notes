## 记录规范

每个实验目录固定包含：

- `README.md`：可读的实验报告
- `data/`：脱敏后的机器可读结果、指标和校验信息
- `artifacts.md`：源项目原始证据的位置与复核方法（如适用）

结果文档区分“实验观察”与“可推广结论”，不把一次运行的性能数字当作所有硬件或模型的普遍结论。
